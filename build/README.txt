TUMBANG PRESO
2v2 arena brawler built on the Filipino street game of the same name. Two Persons
carry a shared can and try to knock it over with a thrown tsinelas (slipper) while
two Defenders -- including one played by a real teammate -- try to guard it and tag
you out first.

RUNNING IT
  Extract this zip if you haven't already, then double-click TumbangPreso.exe.
  TumbangPreso.pck must be in the SAME folder -- the .exe alone will not run (it
  errors or opens a black window without it).

  First launch may show "Windows protected your PC" (SmartScreen), because this
  build is unsigned. Click "More info," then "Run anyway." This is expected and
  safe -- codesigning is on the team's roadmap but isn't done yet.

CONTROLS (keyboard)
  Move            W A S D
  Grab            E   (or Left Click)
  Throw           Q   (or Left/Right Click) -- hold to charge, release to throw
  Bump / shove    Space
  Guard / dash    Left Shift

SINGLE PLAYER (play solo against bots)
  Main Menu -> PLAY -> SINGLE PLAYER -> pick a map, mode, and your seat (Person or
  Prop) -> START MATCH. The three seats you don't take are played by AI.

HOSTING A LAN GAME
  Main Menu -> PLAY -> MULTIPLAYER -> HOST GAME (LAN). The lobby screen shows your
  IP address (e.g. "LOBBY - HOST 192.168.1.7") -- read that out to whoever is
  joining. You pick the map and mode for everyone; empty seats are filled by bots.

  The FIRST time you host, Windows Firewall will ask whether to allow the game
  network access. Click "Allow access" for at least Private networks, or nobody
  will be able to join you -- this looks like a bug but it's just the prompt being
  dismissed or denied.

JOINING A LAN GAME
  Main Menu -> PLAY -> MULTIPLAYER -> type the host's IP address into the "JOIN A
  HOST" field -> JOIN. Leave the port off; it defaults to 8910.

DURING A MATCH
  Esc opens the pause menu (Resume / Settings / Return to Menu).
